# 📚 Hugging Face Spaces Deployment: Real-World Failure Modes Catalog

Detailed technical analysis of scenarios where a Spring Boot / Java application succeeds in local development but fails upon deployment to Hugging Face Spaces.

---

## Failure Mode Matrix

| # | Failure Mode | Severity | Root Cause | Symptoms / Stacktrace | Prevention & Remediation |
|---|---|---|---|---|---|
| **1** | **UID / GID Mismatch (Non-Root UID 1000)** | Critical | HF Spaces enforces container execution under `UID 1000` / `GID 1000`. If the Dockerfile creates an arbitrary user (`appuser` with Alpine system UID `100`), or if files were copied as `root`, UID 1000 has no read/write access. | `AccessDeniedException: /data/...` or `Error: Unable to access jarfile app.jar` | Explicitly create `user` with `-u 1000 -G user` in Alpine; set `WORKDIR /home/user/app` and `COPY --chown=user:user`. |
| **2** | **Port Routing Mismatch (`7860` vs `8080`)** | Critical | HF Spaces reverse proxy maps external traffic exclusively to port `7860`. Spring Boot defaults to `8080` unless `server.port` is explicitly configured. Spring relaxed binding binds `server.port` to `SERVER_PORT`, not `PORT`. | Space stuck on "Starting..." -> HTTP 503 / Port timeout. Logs show `Tomcat started on port 8080`. | Set `server.port: ${PORT:${SERVER_PORT:7860}}` in `application.yml` and `application-prod.yml`. Set `ENV PORT=7860` in Dockerfile. |
| **3** | **Loopback Host Binding (`127.0.0.1`)** | High | App is configured to bind to `127.0.0.1` or `localhost`. External container proxy requests cannot reach loopback. | Proxy returns 502 Bad Gateway. App logs indicate healthy startup with zero HTTP traffic. | Bind to `0.0.0.0` (omit `server.address` or set to `0.0.0.0`). |
| **4** | **Unresolved Placeholder Crash (`${VAR}`)** | Critical | Missing environment variables without a default fallback (`:default`) cause Spring's `PropertySourcesPlaceholderConfigurer` to abort startup. | `BeanCreationException: Could not resolve placeholder 'XYZ' in value "${XYZ}"` | Provide safe defaults or empty strings `${VAR:}` for all non-mandatory config in `application.yml`. |
| **5** | **Missing Java 25 Preview Flag** | Critical | Code compiled with `--enable-preview` (Java 25) requires JVM flag at runtime. | `UnsupportedClassVersionError: Preview features are not enabled (class file version 69.65535)` | Always pass `--enable-preview` in Dockerfile `ENTRYPOINT ["java", "--enable-preview", ...]`. |
| **6** | **Cloud Database SSL Mode Missing** | High | Local Postgres accepts plain TCP. Cloud Postgres (Neon, Supabase) rejects unencrypted connections. | `PSQLException: FATAL: no pg_hba.conf entry for host ..., no encryption` | Append `?sslmode=require` to `DB_URL`. |
| **7** | **Neon Serverless Cold-Start Timeout** | Medium | Neon scales compute to zero on idle. Waking up requires 1-3 seconds. Aggressive connection timeouts fail. | `PSQLException: Connection to ... timed out` | Set Hikari `connection-timeout: 30000` (30s) and `initialization-fail-timeout: 0`. |
| **8** | **Stale Flyway Migration Lock** | High | Container killed mid-migration leaves schema lock active in `flyway_schema_history`. | `FlywayException: Migration failed! Please restore backup` | Verify migration scripts idempotence and resolve schema lock manually if needed. |
| **9** | **Actuator Mail Health Check 503** | High | `spring-boot-starter-mail` registers `MailHealthIndicator`. If SMTP host is unconfigured or dummy, `/actuator/health` returns `DOWN` (503). | Container orchestrator detects 503 and enters restart crash loop. | Disable mail health probe: `management.health.mail.enabled: false`. |
| **10** | **Actuator Protected by Spring Security** | High | If `/actuator/health` requires authentication, HF health check gets 401/403. | Container marked unhealthy and terminated. | Allow public access to `/actuator/health` in `SecurityConfig.java`. |
| **11** | **CORS Credential Wildcard Rejection** | Medium | W3C specification forbids `Access-Control-Allow-Origin: *` when `allowCredentials: true`. | Browser console blocks API requests: `credentials flag is true, but origin is *`. | Use `configuration.setAllowedOriginPatterns(List.of("*"))` instead of wildcard origin. |
| **12** | **CORS Preflight OPTIONS Interception** | Medium | Spring Security filters demand JWT token for HTTP `OPTIONS` requests. | Preflight requests return 401/403 before CORS headers can be returned. | Add `.requestMatchers(HttpMethod.OPTIONS, "/**").permitAll()` in security filter chain. |
| **13** | **OOM Killer Silent Termination (Exit 137)** | High | Hardcoded `-Xmx` too close to container RAM limit. Native memory + Metaspace pushes process over cgroup limit. | Container vanishes abruptly without stack trace. Exit code 137. | Use `-XX:MaxRAMPercentage=75.0` and `-XX:+ExitOnOutOfMemoryError`. |
| **14** | **Alpine `musl` DNS IPv6 Hang** | Medium | `musl libc` resolves A and AAAA records in parallel over UDP. Slow or dropped AAAA responses cause 5s hangs. | Intermittent `UnknownHostException` or socket timeouts on AI API calls. | Add `-Djava.net.preferIPv4Stack=true` to JVM arguments. |
